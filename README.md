# Erfan Academy

سایت آموزشی آکادمی عرفان با PHP و MySQL برای اجرا روی هاست PHP مانند InfinityFree.

## امکانات
- دوره‌های پولی
- ثبت‌نام و ورود
- جستجوی دوره‌ها
- پرداخت آزمایشی
- دیتابیس MySQL

برای اتصال به دیتابیس، `config.php.example` را به `config.php` تبدیل و اطلاعات هاست خود را وارد کنید. رمز واقعی دیتابیس را در GitHub قرار ندهید.
