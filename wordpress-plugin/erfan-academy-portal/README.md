# Erfan Academy Portal (WordPress plugin)

افزونه دوزبانه فارسی/انگلیسی برای پورتال آموزشی Erfan Tooltips.

## نصب
1. پوشه `erfan-academy-portal` را داخل `wp-content/plugins/` قرار دهید.
2. افزونه را از پیشخوان وردپرس فعال کنید.
3. از تنظیمات ← عمومی، «هرکسی می‌تواند نام‌نویسی کند» را فقط در صورت نیاز فعال کنید.
4. یک برگه به نام «پرتال» بسازید و شورت‌کد زیر را در آن قرار دهید:
   `[erfan_academy_portal]`
5. برای ساخت مدرس و پشتیبان، از کاربران ← افزودن کاربر استفاده کنید و نقش مربوطه را انتخاب کنید.

## نقش‌ها
- دانش‌آموز: ثبت‌نام عمومی و داشبورد دانش‌آموز
- مدرس: نقش اختصاصی؛ ساخت حساب توسط مدیر
- پشتیبانی: نقش اختصاصی؛ ساخت حساب توسط مدیر
- مدیر: نقش استاندارد administrator وردپرس

## وضعیت قابلیت‌ها
- ورود وردپرس و ثبت‌نام دانش‌آموز با nonce و اعتبارسنجی پایه
- چهار تجربه نقش‌محور و رابط واکنش‌گرا
- تعویض زبان فارسی/انگلیسی در رابط
- داشبورد و صفحه تنظیمات افزونه
- اتصال درگاه زرین‌پال/ملت، BigBlueButton، مدیریت واقعی دوره‌ها، آزمون‌ها، تیکت‌ها و گزارش‌ها در این نسخه پیاده‌سازی نشده و نیازمند اتصال و پیکربندی جداگانه است.

## نکات امنیتی و عملیاتی
- از HTTPS استفاده کنید.
- رمزهای عبور یا کلیدهای API را در GitHub قرار ندهید.
- برای سایت زنده قبل از فعال‌سازی، روی staging پشتیبان‌گیری و آزمایش کنید.
- این افزونه جایگزین سامانه کامل LMS یا درگاه پرداخت نیست؛ پایه رابط و نقش‌ها را فراهم می‌کند.

## Shortcode
`[erfan_academy_portal]`
