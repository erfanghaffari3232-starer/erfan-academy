# Erfan Academy Online 2.0.0

افزونه وردپرس آکادمی آموزشی صرفاً آنلاین.

## نصب
ZIP افزونه را از GitHub Actions artifact دریافت کنید؛ در وردپرس: افزونه‌ها ← افزودن افزونه تازه ← بارگذاری افزونه. پیش از نصب روی سایت اصلی، پشتیبان بگیرید و ابتدا روی staging آزمایش کنید.

## راه‌اندازی
- برگه «دوره‌های آنلاین»: `[erfan_academy_courses]`
- برگه «پنل من»: `[erfan_academy_portal]`
- برگه «دوره‌های من»: `[erfan_academy_my_courses]`
- دوره‌ها را از منوی «دوره‌های آنلاین» ایجاد و سطح، قیمت، ظرفیت، تاریخ، زمان‌بندی، مدرس و لینک جلسه را تکمیل کنید.
- تنظیمات اولیه اتصال در منوی Erfan Academy قرار دارد.

## امکانات پیاده‌سازی‌شده در این نسخه
- نوع محتوای دوره آنلاین، کاتالوگ و جست‌وجوی دوره
- اطلاعات سطح، مدرس، زمان‌بندی، شهریه، ظرفیت و لینک جلسه
- ثبت درخواست ثبت‌نام کاربران واردشده و جلوگیری از ثبت‌نام تکراری
- نمایش درخواست‌ها و صفحه «دوره‌های من»
- نقش‌های دانش‌آموز، مدرس و پشتیبانی، به‌علاوه مدیر وردپرس
- پنل‌های نقش‌محور اولیه و رابط واکنش‌گرا/راست‌چین
- فیلدهای تنظیمات برای اطلاعات اتصال زرین‌پال و BigBlueButton
- سامانه فقط آنلاین است؛ هیچ کلاس حضوری در نظر گرفته نشده.

## مواردی که هنوز عملیاتی نیستند
پرداخت واقعی و تأیید تراکنش/وب‌هوک، API و ساخت خودکار اتاق BigBlueButton، بانک ملت، آزمون‌ساز، تکلیف، حضور و غیاب کامل، تیکتینگ و گواهی دیجیتال در این نسخه تکمیل نشده‌اند. فیلدهای تنظیمات به‌تنهایی به معنی اتصال این سرویس‌ها نیستند. این نسخه را نسخه اولیه پیشرفته بدانید، نه محصول تجاری نهاییِ تست‌شده.

کلیدها و Secretها را در GitHub منتشر نکنید. آن‌ها را فقط در محیط امن وردپرس وارد کنید.
